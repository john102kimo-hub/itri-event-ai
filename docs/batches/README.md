# 施工批次索引

每一批「改了什麼、為什麼這樣改、踩到什麼坑」的紀錄。**規格（定位、資料模型、七個坑、意圖、prompt 規則、不要做的事、人類待辦）在 [../../LINE-PLAN.md](../../LINE-PLAN.md)**，這裡只放批次。

## 怎麼用

- 程式碼註解寫「批次 N」（或「LINE-PLAN.md 批次 N」）時，在下表找 N，點右邊的檔案；也可以 `grep -rn "批次 N" docs/batches/`。
- 紀錄是當時的狀態：行號、檔案內容都可能早就變了，**動工前自己 grep 現行程式碼**。
- 沒有獨立章節的批次編號：5、29、87、99（做法併在鄰近批次，或沒有留下獨立紀錄）；「—」是沒有編號的獨立章節。

## 新的一批怎麼記（CLAUDE.md 第 5 條）

1. 往最新那份檔案（檔名數字最大的）後面接一個 `## 批次 N：標題（日期）` 章節——**標題格式要照這樣寫**（`批次 N：`），索引與 `test/test-docs.mjs` 靠它抓。
2. 在下面的表補一行（編號、標題、檔案）。`test/test-docs.mjs` 會檢查每個批次標題都有列在這裡。
3. 最新那份超過約 900 行，就開下一份（`10-batch-NNN.md`（NNN 是那份的第一個批次編號）），並到 [../../LINE-PLAN.md](../../LINE-PLAN.md) 第 5 節的表補一行。
