# 機構資料：預擬版（2026-11-10）

給朱朱填的第一版。**這份只有框架，沒有任何一條是確定的事實**——我不知道工研院現在的窗口、電話、流程，也不能憑印象替工研院寫。

## 怎麼用

1. 把下面程式區塊裡的整段貼進後台「記者與邀訪」→「機構資料」，按儲存。**貼進去也安全**：每一條都帶「【待填】」或「【待核對】」，米亞**不會使用**這些條目，後台會在下面列出「還沒填完」的清單，讓你知道還剩幾條。
2. 一條一條填：把「【待填：…】」整段（含括號）換成真正的內容，**日期改成填的那天**。不需要的條目整行刪掉就好。
3. 「【待核對】」是我寫了一個常見說法、但沒辦法確認的：核對無誤就拿掉「【待核對】」三個字，不對就改。
4. 全部填完後，用沒綁定活動的帳號問一次「怎麼申請採訪」「工研院有幾個所」「想參訪要找誰」，看米亞回的對不對。
5. 上限 6,000 字（目前預擬版約 2,100 字，填完大概會長一點，超過就刪掉用不到的條目）。

## 填的原則

- **不放會變的數字**（人數、經費、研究所數量）——寫「詳見官網」比寫一個過期的數字安全；放了就要定期複查。
- **電話、Email、地址要寫完整**，記者會直接照著打。
- 一條講一件事，兩三句內寫完；米亞回答時會引用整條。
- **不放**院方對個案的口徑（那是活動知識庫的【口徑外的問題】）、未公開的內容、對外承諾的時間。
- 一條裡有多個窗口時，寫清楚「什麼情況找誰」。

## 涵蓋的題目類型（以記者與一般洽詢實際會問的為準）

| 類別 | 會被問到的例子 | 條目 |
|---|---|---|
| 採訪與媒體 | 怎麼申請採訪、找誰、非上班時間、能不能拍、要不要證件、可不可以指定受訪者、新聞稿與照片哪裡拿、可不可以引用、報導有誤怎麼聯繫、怎麼加入媒體名單 | 1～10 |
| 參訪 | 想參訪、媒體想拍攝場域、人數與費用限制、外賓參訪 | 11～14 |
| 技術與合作 | 技術授權、委託研發、檢測驗證、新創育成、專利、產學合作、國際合作 | 15～21 |
| 機構資訊 | 簡介、成立時間、有哪些研究所、核心領域、總部在哪、院長是誰、歷史、名稱與縮寫、官網與社群、得過什麼獎 | 22～32 |
| 活動、人才與其他 | 活動資訊哪裡查、報名、電子報、徵才與實習、課程、場地租借、總機、交通停車、投訴與建議 | 33～41 |

**這份不可能涵蓋「所有可能性」**：記者會問到我們想不到的題目，米亞照規矩會說「目前尚未有這部分資料」並問要不要轉介真人，這就是設計好的出口。要補強的方法是看後台 `route_log` 與「疑似答不出來」的題目，把常被問到的補進來。
