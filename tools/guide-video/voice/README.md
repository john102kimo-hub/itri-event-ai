# 米亞的聲音

**這個資料夾就是米亞的聲音。以後這支 LINE 只要有需要出聲的東西——使用說明影片、
活動預告短片、語音訊息——一律用這裡的聲音，不要再另外挑語音、也不要再用 edge-tts。**

聲音是朱朱在 [Vidnoz 文字轉語音](https://tw.vidnoz.com/text-to-speech.html) 上挑的
童聲，比合成語音自然，也符合米亞這個角色。原始匯出檔留在
`mia-voice-ref.wav`（16 kHz 單聲道，27.4 秒，六句）。

## 兩種情況

### 台詞沒變（重錄畫面、重做影片）

直接用 `mia-voice-ref.wav`，不用回 Vidnoz：

```bash
cd tools/guide-video/voice
python3 cute.py          # → cvo0.wav … cvo5.wav
```

### 台詞變了，或要做新的影片

得回 Vidnoz 用**同一個語音**把新台詞念一次，匯出成 wav 放進這個資料夾，然後：

```bash
MIA_VOICE=新檔名.wav python3 cute.py
```

匯出時有一個要求：**每句之間停滿 1 秒左右**。`cute.py` 靠靜音把整段切成一句一檔，
一句一檔是刻意的——整段一次念完，長度不可能剛好落在畫面每 5 秒的切點上，畫面換了
口白還在講上一格，比沒有口白更糟。段數對不上台詞句數時腳本會直接停下來，不會硬切。

> **Vidnoz 上的語音是「HsiaoYu（Taiwan）」**（朱朱 2026-09-10 提供）。換台詞時要挑
> 同一個，不然聲音會跟現在這支影片對不起來。
>
> 順帶一提：這跟備援的 `../vo.py` 用的 `zh-TW-HsiaoYuNeural` 是**同一個語音**。
> 兩邊聽起來差這麼多，差在 Vidnoz 那邊的語調與情緒設定，不是換了一個人——所以
> 「回 Vidnoz 用同一個語音」這句話是有意義的，改用 edge-tts 直接合成不會等價。

## `cute.py` 做了什麼

朱朱聽完 Vidnoz 原檔的評語是「還是有點 AI 感覺，幫我改得可愛活潑一點」。AI 感來自
三件事，三件分別處理：

| 症頭 | 處理 |
| --- | --- |
| 音色偏成人、偏平 | `rubberband` 往上移調 1.7～2.4 個半音（共振峰跟著移＝聽起來像個子小一點的人） |
| 16 kHz 取樣，8 kHz 以上全空，像在講電話 | `aexciter` 把高頻諧波補回來（9 kHz 以上從 −54 dB 拉到 −43 dB） |
| 每句的音高語速一模一樣＝在念稿 | 逐句給不同的移調與語速，打招呼那句跟收尾那句最亮最快 |

再加上 `agate` 壓底噪、`acompressor` 穩音量、一點點 `aecho` 當空間感，最後六句對齊
到同一個平均音量（−20 dB）。

## 兩個踩過的坑

**`aexciter` 一定要排在 `aresample=44100` 後面。** 原檔是 16 kHz，Nyquist 只有
8 kHz，直接叫 exciter 去合成 15 kHz 的諧波會整段折返成鋸齒雜訊。症狀很好認：峰值
卡在 0.0 dB、直方圖全部擠在同一格，聽起來像方波。

**不要用單次 `loudnorm` 對齊音量。** 它是動態的，遇到句子頭尾那半秒的靜音會把底噪
一路推上來——第一版六句的尾巴全都是一模一樣的 −4.2 dB，那不是聲音，是被放大的
嘶聲。要對齊音量就量完再套固定增益（`volume`）。
